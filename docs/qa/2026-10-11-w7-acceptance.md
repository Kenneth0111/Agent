## 本轮发现并修复

独立审查以实际 validReport 复现：同一合法报告的 publicationUrl 从字符串改为 null，前端校验由 true 变 false。后端发布 API 允许仅提供作品 ID，故合法报告会无法展示，创建响应也可能被误判为未确认、历史列表整批拒绝。

修复仅允许 publicationUrl 为 string/null，并在空链接处保留原计划关联与提示；topicId/scriptId 仍须是完整的已确认内容标识，跨账号和非法数值链接继续拒绝，不扩大其他字段规则。旧校验运行更新回归得到 1 失败/8 通过，修复后完整前端 **74 项及类型/生产构建通过**。生成场景验证成功后清理待确认 UUID；历史场景保留计划/脚本并不渲染假链接。

OperationReviewTest 使用真实数据库和公开业务服务：同一作品登记两个原计划项，其中一个只有 ID、没有 URL，事实收集返回两个关联并保留 null。`OperationReviewTest,ScheduleServiceTest` 专项 verify **6 项、0 失败/错误/跳过**。这是完整 57 项通过后的追加字段覆盖，后端业务实现未修改。

独立复审没有新增问题；新增发布边界已覆盖，未进行无关重构。本轮页面只修改 null 链接校验与文字，不重跑前轮全部浏览器流程；实际数据库关联与组件读取/生成分别验证，既有桌面/手机验收记录仍保留。
